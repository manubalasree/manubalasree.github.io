# VirtMicro Brand Kit

Logo, colours, favicons, social images and fonts for virtmicro.com.

Start with **BRAND-GUIDE.md**. Quick picks:

- Website or document header: `logo/svg/virtmicro-horizontal-color.svg`
- On a dark background: `logo/svg/virtmicro-horizontal-reversed.svg`
- Profile picture: `social/avatar-1024.png`
- Favicons: everything in `favicon/`
- Link previews: `social/og-image-1200x630.png`

SVG files have the wordmark converted to outlines, so no font install is needed.
Space Grotesk (in `fonts/`) is licensed under the SIL Open Font License.
